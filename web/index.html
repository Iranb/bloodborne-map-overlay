Bloodborne 探索地圖

沿用黑魂 2 地圖的旋轉、平移、區域切換與收集清單操作。點擊地圖標記或清單可聚焦；勾選條目即可記錄完成。

切層：隱藏高度滑桿以上的地形。選中目標時，切層高度會移到目標附近。這是高度剖切，不是遊戲中的樓層編號。

進度：三份獨立獵人記錄，儲存在本機；可匯出 JSON 備份。尚未接入人物實時位置或存檔事件，勾選不會修改遊戲。

範圍：本體＋老獵人 DLC，16 組區域。地形來自本機遊戲的低精度碰撞資料；不含程序生成金杯地牢。地形不表示所有門、機關當前可通行。固定拾取事件不等於完整全收集攻略，未涵蓋所有商店、掉落與劇情獎勵。Boss 座標是初始位置。

NPC：綠色 N 為可交談／互動角色的初始或劇情候選位置。同地點的多個劇情状态已合併；不同地點分別記錄。並非人物的即時位置，也不表示角色目前在場。

快捷鍵：Ctrl+Alt+M 顯示／隱藏，Ctrl+Alt+F 大小窗，Ctrl+Alt+L 鼠標穿透。可拖動左上角標題移動窗口。視窗置頂和透明度可從托盤調整。

資料來源：本機 MSBB／HKX／PARAM／FMG；SoulsFormats、MVDX_Classic、Soulstruct 事件參考。三維引擎：Three.js。未見之村有兩個碰撞部件缺失，局部地形可能不完整。
