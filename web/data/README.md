# Local map data

Generate `maps.json`, `layers.json` and the 16 `*.mesh` files from your local Bloodborne installation. These files are excluded from Git and desktop downloads. See [DATA_SETUP.md](../../docs/DATA_SETUP.md).

`quests.json` contains the original bilingual quest notes; `boss-flags.json` contains read-only save-format offsets. Neither contains a save or extracted map geometry.
